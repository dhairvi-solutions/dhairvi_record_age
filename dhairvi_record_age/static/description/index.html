Dhairvi Record Age – Days Since Created

See how many calendar days have passed since a record was created.

Add a Record Age column that shows whole calendar days since a record was created. The value is calculated from Odoo’s own create_date whenever you open the view.

Automatic Record Age

Created today = 0. Created yesterday = 1. Created ten days ago = 10. Hours are ignored; this is a calendar-day count, using the user’s timezone — not the browser clock.

No Configuration

Install the app and open a supported list view. There is no settings page, no extra menu, no cron, and nothing to schedule.

Lightweight

One computed integer field. It is not stored, so it cannot go out of date. No extra database tables and no extra access rights.

No External Integration

Everything runs inside Odoo. No third-party APIs, webhooks, OAuth, or extra Python packages.

Odoo Native

Standard ORM computed fields and inherited list/form views. Compatible with Odoo 16, 17, 18, and 19.

Multi-Application Support

Record Age appears on the apps you actually use. Unused applications are not forced as dependencies. A Sales-only database installs and runs without Purchase, Manufacturing, or Helpdesk.

What you get

  • Single module Dhairvi Record Age — no extra companion apps
  • Computed record_age_days integer field, recalculated on each read
  • List and form columns on CRM, Sales, Purchase, Invoices, Manufacturing, Project, and Helpdesk when those apps are installed
  • CRM search filters on create_date (Created Today, Older than 7 / 14 / 30 Days)
  • Support for Odoo 16, 17, 18, and 19 from one codebase
